# Solana IDL Specification v0.1.0

> First version based on the [`anchor-lang-idl-spec`](https://docs.rs/anchor-lang-idl-spec/0.1.0/anchor_lang_idl_spec/) Rust crate (version `0.1.0`).

A Solana IDL is a JSON description of a program's public interface. It can be stored on-chain via the [Program Metadata](https://github.com/solana-program/program-metadata) program.

### Default Omission

Fields annotated with a default value are **omitted from JSON** when they equal that default. For example, a boolean that defaults to `false` will not appear in the output, and an empty array will be omitted entirely. Parsers must treat missing fields as their documented default. The "Default" column in each table indicates the value used when the field is absent.

## Root Object (`Idl`)

The top-level object of a Solana IDL JSON file.

| Field          | Type                                      | Default    | Description |
|----------------|-------------------------------------------|------------|-------------|
| `address`      | `string`                                  | --         | The on-chain address of the deployed program. |
| `metadata`     | [`IdlMetadata`](#idlmetadata)             | --         | Program name, version, spec version, and optional metadata. |
| `docs`         | `string[]`                                | `[]`       | Top-level documentation strings for the program. Omitted when empty. |
| `instructions` | [`IdlInstruction[]`](#idlinstruction)     | --         | All instructions the program exposes. |
| `accounts`     | [`IdlAccount[]`](#idlaccount)             | `[]`       | Account types the program defines (with discriminators). Omitted when empty. |
| `events`       | [`IdlEvent[]`](#idlevent)                 | `[]`       | Events the program can emit. Omitted when empty. |
| `errors`       | [`IdlErrorCode[]`](#idlerrorcode)         | `[]`       | Custom error codes. Omitted when empty. |
| `types`        | [`IdlTypeDef[]`](#idltypedef)             | `[]`       | Custom type definitions (structs, enums, type aliases). Omitted when empty. |
| `constants`    | [`IdlConst[]`](#idlconst)                 | `[]`       | Exported constants. Omitted when empty. |

```json
{
  "address": "Fg6PaFpoGXkYsidMpWTK6W2BeZ7FEfcYkg476zPFsLnS",
  "metadata": { "name": "my_program", "version": "0.1.0", "spec": "0.1.0" },
  "instructions": [ ... ],
  "accounts": [ ... ],
  "types": [ ... ]
}
```

## Metadata

### IdlMetadata

| Field          | Type                                        | Default | Description |
|----------------|---------------------------------------------|---------|-------------|
| `name`         | `string`                                    | --      | Program name (typically snake_case). |
| `version`      | `string`                                    | --      | Program version (semver). |
| `spec`         | `string`                                    | --      | IDL spec version. Must be `"0.1.0"` for this spec. |
| `description`  | `string`                                    | --      | Human-readable program description. Omitted when absent. |
| `repository`   | `string`                                    | --      | URL of the source repository. Omitted when absent. |
| `dependencies` | [`IdlDependency[]`](#idldependency)         | `[]`    | External program dependencies. Omitted when empty. |
| `contact`      | `string`                                    | --      | Contact information for the program maintainer. Omitted when absent. |
| `deployments`  | [`IdlDeployments`](#idldeployments)         | --      | Deployment addresses per cluster. Omitted when absent. |

### IdlDependency

| Field     | Type     | Default | Description |
|-----------|----------|---------|-------------|
| `name`    | `string` | --      | Dependency name. |
| `version` | `string` | --      | Dependency version (semver). |

### IdlDeployments

| Field      | Type     | Default | Description |
|------------|----------|---------|-------------|

| `localnet` | `string` | --      | Localnet program address. Omitted when absent. |

## Instructions

### IdlInstruction

Describes a single instruction the program can process.

| Field           | Type                                                          | Default | Description |
|-----------------|---------------------------------------------------------------|---------|-------------|
| `name`          | `string`                                                      | --      | Instruction name (camelCase). |
| `docs`          | `string[]`                                                    | `[]`    | Documentation strings. Omitted when empty. |
| `discriminator` | [`IdlDiscriminator`](#idldiscriminator)                       | --      | Byte array that uniquely identifies this instruction. Length and derivation are framework-specific. |
| `accounts`      | [`IdlInstructionAccountItem[]`](#idlinstructionaccountitem)   | --      | Accounts required by this instruction. |
| `args`          | [`IdlField[]`](#idlfield)                                     | --      | Instruction arguments. |
| `returns`       | [`IdlType`](#idltype)                                         | --      | Return type (if the instruction returns data via return_data). Omitted when absent. |

### IdlInstructionAccountItem

An **untagged** union -- each element is either a single account or a composite (nested group). There is no discriminator field; parsers distinguish the two by structure: a `Composite` has an `accounts` array, a `Single` does not.

| Variant     | Type                                                    | Description |
|-------------|---------------------------------------------------------|-------------|
| `Composite` | [`IdlInstructionAccounts`](#idlinstructionaccounts)     | A named group of accounts. Matched first during deserialization. |
| `Single`    | [`IdlInstructionAccount`](#idlinstructionaccount)       | A single account entry. |

### IdlInstructionAccount

| Field       | Type                        | Default | Description |
|-------------|-----------------------------|---------|-------------|
| `name`      | `string`                    | --      | Account name (camelCase). |
| `docs`      | `string[]`                  | `[]`    | Documentation strings. Omitted when empty. |
| `writable`  | `boolean`                   | `false` | Whether the account is written to. Omitted when `false`. |
| `signer`    | `boolean`                   | `false` | Whether the account must sign the transaction. Omitted when `false`. |
| `optional`  | `boolean`                   | `false` | Whether the account is optional. Omitted when `false`. |
| `address`   | `string`                    | --      | Expected fixed address (e.g. a well-known program). Omitted when absent. |
| `pda`       | [`IdlPda`](#idlpda)         | --      | PDA derivation info for this account. Omitted when absent. |
| `relations` | `string[]`                  | `[]`    | Names of related accounts (constraint references). Omitted when empty. |

Example showing how defaults are omitted -- a read-only, non-signer account with a PDA:

```json
{
  "name": "counter",
  "writable": true,
  "pda": { "seeds": [ ... ] }
}
```

### IdlInstructionAccounts

A named group of accounts (composite).

| Field      | Type                                                        | Default | Description |
|------------|-------------------------------------------------------------|---------|-------------|
| `name`     | `string`                                                    | --      | Group name. |
| `accounts` | [`IdlInstructionAccountItem[]`](#idlinstructionaccountitem) | --      | Nested account items. |

### IdlField

A named, typed field used in instruction arguments and struct definitions.

| Field  | Type                    | Default | Description |
|--------|-------------------------|---------|-------------|
| `name` | `string`                | --      | Field name (camelCase). |
| `docs` | `string[]`              | `[]`    | Documentation strings. Omitted when empty. |
| `type` | [`IdlType`](#idltype)   | --      | The field's type. |

## Types

### IdlTypeDef

Defines a custom type (struct, enum, or type alias).

| Field           | Type                                              | Default    | Description |
|-----------------|---------------------------------------------------|------------|-------------|
| `name`          | `string`                                          | --         | Type name (PascalCase). |
| `docs`          | `string[]`                                        | `[]`       | Documentation strings. Omitted when empty. |
| `serialization` | [`IdlSerialization`](#idlserialization)            | `"borsh"`  | Serialization format. Omitted when `"borsh"`. |
| `repr`          | [`IdlRepr`](#idlrepr)                             | --         | Memory representation hint. Omitted when absent. |
| `generics`      | [`IdlTypeDefGeneric[]`](#idltypedefgeneric)       | `[]`       | Generic parameters. Omitted when empty. |
| `type`          | [`IdlTypeDefTy`](#idltypedefty)                   | --         | The kind of type (struct, enum, or alias). |

> **Note:** The JSON key is `"type"`, not `"ty"`. The Rust source uses `#[serde(rename = "type")]`.

### IdlTypeDefTy

Tagged union describing the shape of a type definition. Uses `"kind"` as the tag field.

| Variant  | Fields | Description |
|----------|--------|-------------|
| `struct` | `fields`: [`IdlDefinedFields`](#idldefinedfields) (optional) | A struct with named or tuple fields. |
| `enum`   | `variants`: [`IdlEnumVariant[]`](#idlenumvariant) | An enum with variants. |
| `type`   | `alias`: [`IdlType`](#idltype) | A type alias. |

```json
{ "kind": "struct", "fields": [ ... ] }
{ "kind": "enum", "variants": [ ... ] }
{ "kind": "type", "alias": "u64" }
```

### IdlEnumVariant

| Field    | Type                                                   | Default | Description |
|----------|--------------------------------------------------------|---------|-------------|
| `name`   | `string`                                               | --      | Variant name (PascalCase). |
| `fields` | [`IdlDefinedFields`](#idldefinedfields)                | --      | Variant data, if any. Omitted when absent. |

### IdlDefinedFields

An **untagged** union describing the fields of a struct or enum variant. The variant is inferred from the shape of the JSON array:

| Variant | JSON Shape | Description |
|---------|------------|-------------|
| `Named` | Array of objects with `name` and `type` keys | Named fields (like a Rust struct). |
| `Tuple` | Array of type values (strings or objects)     | Positional fields (like a Rust tuple struct). |

```json
// Named
[{ "name": "authority", "type": "pubkey" }, { "name": "count", "type": "u64" }]

// Tuple
["pubkey", "u64"]
```

### IdlType

The type system. All Solana/Rust primitive types are supported, plus container types and references to user-defined types.

#### Primitives

| Value      | Description |
|------------|-------------|
| `"bool"`   | Boolean. |
| `"u8"`     | Unsigned 8-bit integer. |
| `"i8"`     | Signed 8-bit integer. |
| `"u16"`    | Unsigned 16-bit integer. |
| `"i16"`    | Signed 16-bit integer. |
| `"u32"`    | Unsigned 32-bit integer. |
| `"i32"`    | Signed 32-bit integer. |
| `"f32"`    | 32-bit float. |
| `"u64"`    | Unsigned 64-bit integer. |
| `"i64"`    | Signed 64-bit integer. |
| `"f64"`    | 64-bit float. |
| `"u128"`   | Unsigned 128-bit integer. |
| `"i128"`   | Signed 128-bit integer. |
| `"u256"`   | Unsigned 256-bit integer. |
| `"i256"`   | Signed 256-bit integer. |
| `"bytes"`  | Variable-length byte array (`Vec<u8>`). |
| `"string"` | UTF-8 string. |
| `"pubkey"` | Solana public key (32 bytes). |

#### Container Types

| JSON Representation | Description |
|---------------------|-------------|
| `{ "option": <IdlType> }` | Optional value. |
| `{ "vec": <IdlType> }` | Variable-length list. |
| `{ "array": [<IdlType>, <length>] }` | Fixed-length array. `length` is a number or `{ "generic": "<Name>" }`. |
| `{ "defined": { "name": "<TypeName>", "generics": [...] } }` | Reference to a user-defined type from the `types` array. `generics` is omitted when empty. |
| `{ "generic": "<Name>" }` | A generic type parameter. |

### IdlArrayLen

Array lengths are represented without a wrapper tag:

| Form | Example | Description |
|------|---------|-------------|
| Number | `32` | A fixed numeric length (untagged, bare number). |
| Object | `{ "generic": "N" }` | A generic const parameter name. |

### IdlGenericArg

Used when instantiating a generic type. Uses `"kind"` as the tag field.

| Variant | Fields | Description |
|---------|--------|-------------|
| `type`  | `type`: [`IdlType`](#idltype) | A type argument. |
| `const` | `value`: `string` | A const argument. |

> **Note:** The `type` variant's field is `"type"` in JSON, not `"ty"`.

```json
{ "kind": "type", "type": "pubkey" }
{ "kind": "const", "value": "8" }
```

### IdlTypeDefGeneric

Declares a generic parameter on a type definition. Uses `"kind"` as the tag field.

| Variant | Fields | Description |
|---------|--------|-------------|
| `type`  | `name`: `string` | A generic type parameter. |
| `const` | `name`: `string`, `type`: `string` | A const generic parameter with its type. |

> **Note:** The `const` variant's type field is `"type"` in JSON, not `"ty"`.

```json
{ "kind": "type", "name": "T" }
{ "kind": "const", "name": "N", "type": "usize" }
```

### IdlSerialization

Describes how the type is serialized on-chain. Uses `#[serde(rename_all = "lowercase")]`.

| Value              | Description |
|--------------------|-------------|
| `"borsh"`          | Borsh serialization (default). |
| `"bytemuck"`       | Zero-copy via `bytemuck`. |
| `"bytemuckunsafe"` | Zero-copy via `bytemuck` (unsafe). |
| `{ "custom": "<name>" }` | A custom serialization format. |

> **Note:** The variant `BytemuckUnsafe` is serialized as `"bytemuckunsafe"` (all lowercase) due to `rename_all = "lowercase"`.

### IdlRepr

Memory representation hint, mirroring Rust's `#[repr(...)]`. Uses `"kind"` as the tag field with `rename_all = "lowercase"`. The modifier fields are flattened into the same object.

| Variant        | Additional Fields | Description |
|----------------|-------------------|-------------|
| `"rust"`       | `packed`: `boolean`, `align`: `number` (optional) | Default Rust representation. |
| `"c"`          | `packed`: `boolean`, `align`: `number` (optional) | C-compatible representation. |
| `"transparent"`| _(none)_ | Transparent representation (single-field wrapper). |

```json
{ "kind": "rust", "packed": false }
{ "kind": "c", "packed": true, "align": 8 }
{ "kind": "transparent" }
```

### IdlReprModifier

The modifier fields used by the `rust` and `c` variants of `IdlRepr`. These are flattened into the `IdlRepr` object alongside the `kind` field.

| Field    | Type              | Default | Description |
|----------|-------------------|---------|-------------|
| `packed` | `boolean`         | `false` | Whether the type uses packed layout. Omitted when `false`. |
| `align`  | `number`          | --      | Explicit alignment in bytes. Omitted when absent. |

## PDA Seeds

### IdlPda

Describes how a Program Derived Address is computed.

| Field     | Type                            | Default | Description |
|-----------|---------------------------------|---------|-------------|
| `seeds`   | [`IdlSeed[]`](#idlseed)        | --      | Ordered list of seeds. |
| `program` | [`IdlSeed`](#idlseed)          | --      | The program to derive against (defaults to the current program). Omitted when absent. |

### IdlSeed

A tagged union for PDA seed sources. Uses `"kind"` as the tag field with `rename_all = "lowercase"`. The inner struct fields are flattened into the same object.

| Variant   | Type                                    | Description |
|-----------|-----------------------------------------|-------------|
| `const`   | [`IdlSeedConst`](#idlseedconst)        | A constant byte value. |
| `arg`     | [`IdlSeedArg`](#idlseedarg)            | A value from an instruction argument. |
| `account` | [`IdlSeedAccount`](#idlseedaccount)    | A value from an account field. |

```json
{ "kind": "const", "value": [99, 111, 117, 110, 116, 101, 114] }
{ "kind": "arg", "path": "user_id" }
{ "kind": "account", "path": "authority", "account": "TokenAccount" }
```

### IdlSeedConst

| Field   | Type       | Default | Description |
|---------|------------|---------|-------------|
| `value` | `number[]` | --      | Raw bytes of the constant seed. |

### IdlSeedArg

| Field  | Type     | Default | Description |
|--------|----------|---------|-------------|
| `path` | `string` | --      | Dot-delimited path to the instruction argument (e.g. `"user_id"` or `"config.owner"`). |

### IdlSeedAccount

| Field     | Type     | Default | Description |
|-----------|----------|---------|-------------|
| `path`    | `string` | --      | Dot-delimited path to the account field. |
| `account` | `string` | --      | The account type name (if resolving a field from a deserialized account). Omitted when absent. |

## Type Aliases

### IdlDiscriminator

```
type IdlDiscriminator = number[]
```

A variable-length array of bytes used to uniquely identify instructions, accounts, and events on-chain. The length and derivation method are framework-specific:

- **Anchor**: 8 bytes, first 8 bytes of the SHA-256 hash of a canonical string (e.g. `"global:<instruction_name>"` for instructions).
- **Quasar**: 1 byte, developer-assigned numeric discriminator.
